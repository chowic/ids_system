# ids_system
# 轻量级混合型网络攻击检测系统 (Lightweight Hybrid IDS)

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![PyQt5](https://img.shields.io/badge/PyQt5-5.15-green.svg)](https://pypi.org/project/PyQt5/)
[![Scapy](https://img.shields.io/badge/Scapy-2.5-orange.svg)](https://scapy.net/)
[![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-1.3-yellow.svg)](https://scikit-learn.org/)
[![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)](LICENSE)

本项目是针对当前复杂隐蔽网络威胁研发的**轻量级混合型网络入侵检测系统 (Lightweight Hybrid IDS)**。系统深度融合了 **Python + PyQt5 + Scapy**，集成了特征匹配、AI无监督异常检测、TLS加密流量指纹识别及自适应行为基线等多引擎协同矩阵，并创新性地引入了告警智能降噪与攻击链演进重构模块，旨在为企事业单位及科研网络提供一款高效、轻量、直观的实战化安全监控与运维分析平台。

---

## 🌟 核心特色功能

- **智能流量采集与网卡自适应适配**：依托 Scapy 抓包框架，内置跨平台智能网卡过滤机制，在 Windows/Linux 环境下自动剔除冗余虚拟接口及回环接口，一键精准锁定并捕获真实的物理局域网流量。
- **多引擎混合威胁检测矩阵**：
  - **误用检测引擎**：基于高性能模式串与正则表达式匹配，精准拦截 SQL 注入、XSS、远程代码执行及木马后门等已知攻击。
  - **AI 智能分析引擎**：基于 `scikit-learn` 的 **Isolation Forest (孤立森林)** 无监督学习算法，提取五维流量特征向量，有效捕获未知攻击与零日威胁。
  - **TLS 加密流量检测**：深度解析 TLS 握手阶段明文元数据，提取 `JA3` 指纹与 `SNI` 域名，精准识别隐蔽的加密 C2 外联通信。
  - **自适应动态行为基线**：通过滑动窗口统计端口扫描、暴力破解、异常外联、横向扩散及带宽异常。
- **告警智能降噪与风险量化**：内置 `AlertDeduplicator` 时间窗口聚合机制（60秒内同类告警自动去重聚合、次数累计），结合多级资产严重度动态评分体系，彻底解决传统 IDS 的“告警疲劳”痛点。
- **攻击链演进重构与溯源分析**：自动将离散单点告警按源 IP 智能串联并按时间排序，动态映射至标准网络杀伤链 (Kill Chain) 五大演进阶段（侦察、漏洞利用、C2通信、横向扩散等），一键直观呈现攻击者的演进全貌与整体风险等级。
- **PyQt5 响应式宽屏可视化控制台**：基于 MVC 设计模式构建 1400x700 宽屏运维操作台，依托多线程异步信号槽 (`pyqtSignal`) 机制彻底实现底层高并发抓包与前端 UI 的解耦，支持实时多维统计、多色高亮告警表格与日志持久化导出。

## 📂 项目模块结构

```text
Lightweight-Hybrid-IDS/
│
├── main.py                  # 系统主入口及启动脚本
├── gui.py                   # PyQt5 可视化运维控制台与主界面逻辑
├── packet_capture.py        # 底层抓包模块与智能网卡适配器
├── signature_detector.py    # 误用检测引擎（正则表达式特征匹配）
├── anomaly_detector.py      # 异常行为检测引擎（基线与五类异常判定）
├── ai_detector.py           # AI智能分析引擎（Isolation Forest 模型）
├── tls_detector.py          # TLS加密流量检测引擎（JA3/SNI 识别）
├── alert_manager.py         # 告警管理器、时间窗口去重与日志持久化
├── attack_chain.py          # 攻击链关联分析与 Kill Chain 映射模块
├── data/
│   ├── signatures.txt       # 攻击特征规则库文件
│   └── baseline.json        # 流量行为基线缓存文件
└── tests/
    ├── test_attack.py       # 自动化攻击流量生成与测试脚本
    └── test_attackchain.py  # 攻击链演进流程模拟测试脚本
```

## ⚙️ 环境配置与安装

### 1. 软硬件环境要求
- **操作系统**：Windows 11 / 10 (推荐) 或 Linux / macOS
- **Python 版本**：Python 3.10+
- **底层抓包驱动**：Windows 平台需安装 **Npcap**（安装时请勾选 *“Install in WinPcap API-compatible Mode”* 选项）。

### 2. 依赖库安装
克隆代码库并执行以下命令一键安装 Python 依赖包：

```bash
git clone https://github.com/your-username/Lightweight-Hybrid-IDS.git
cd Lightweight-Hybrid-IDS
pip install scapy PyQt5 scikit-learn numpy
```

## 🚀 快速上手指南

### 1. 准备特征库
确保 `data/signatures.txt` 文件中包含有效的攻击特征规则（系统默认内置 47 条规则，覆盖 SQL 注入、XSS、命令执行、WebShell 及木马后门等）。

### 2. 启动系统
运行主程序启动图形化运维控制台：

```bash
python main.py
```

### 3. 操作说明
1. **选择网卡**：在控制台顶端工具栏选择目标物理网卡（系统会自动过滤虚拟网卡）。
2. **基线学习**：点击“基线学习”按钮预热系统行为基线（或加载已有基线）。
3. **开始检测**：点击“开始检测”，底层多线程异步抓包引擎启动，实时捕获并多维并行检测流量。
4. **告警查看**：右侧实时告警表格将高亮展示各类威胁告警（高危/严重告警自动标红/紫）。
5. **攻击链溯源**：点击“攻击链详情”标签页查看按源 IP 自动串联的 Kill Chain 攻击演进全貌。

## 🧪 测试与验证

项目提供了一套完整的自动化攻击模拟测试脚本，可用于验证系统的各项检测与降噪能力：

```bash
# 运行单一或组合攻击流量模拟测试
python tests/test_attack.py

# 模拟完整四阶段攻击链演进测试
python tests/test_attackchain.py
```

**测试效果验证指标**：
- **SQL注入/XSS/命令执行**：触发特征匹配引擎，实时输出高危告警。
- **端口扫描与暴力破解**：触发行为异常检测引擎，精准捕捉探测行为。
- **AI 异常检测**：Isolation Forest 模型成功识别偏离基线的极端高频流量。
- **TLS 恶意通信**：成功从 ClientHello 中解析并拦截携带恶意 SNI (`ngrok.io`) 的加密流量。
- **告警降噪**：在 60 秒时间窗口内重复发送同类攻击，系统仅更新计数而不新增日志行数，彻底消除告警风暴。
